\# LeiloesTDSat 



\## Nome do projeto



LeiloesTDSat



\## Sobre o projeto



O LeiloesTDSat é um sistema desenvolvido para auxiliar nas rotinas de uma casa de leilões. O sistema permite realizar o cadastro e a listagem de produtos, facilitando o gerenciamento das informações relacionadas aos itens disponíveis para os leilões.



\## Tecnologias utilizadas



\* Java

\* MySQL

\* NetBeans

\* Git

\* GitHub
